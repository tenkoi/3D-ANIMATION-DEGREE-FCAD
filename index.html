The course

One class, two levels

3D Animation Principles and 3D Animation run together as one class. All the topics from both courses are covered across the same 14 weeks.

1

Principles first

History, the 12 principles of animation and the physics of motion. You learn why things move before you learn how to key them.

2

Objects, not characters

All work uses bouncing balls, props, vehicles and simple mechanisms. There's no character rigging, so you can spend the time on motion quality.

3

Build to a scene

Each skill feeds into the final project, Alive Townscape: a 15–20 second animated town with a moving camera and at least three animated objects.

Start here

Introduction to Blender 5

Blender is free and open-source software for 3D modelling, animation and rendering. This course uses Blender 4.5 LTS or any 5.x release, and the animation tools work the same way in both.

Before Week 1

Setting up

  • Download: get the latest version from blender.org/download. It's free on Windows, macOS and Linux.
  • Version: use 4.5 LTS or 5.x. Older tutorials made in 2.8–3.x mostly still apply, but some menus have moved.
  • Workspace: open the Animation workspace tab at the top of the window. It already lays out the Dope Sheet, Timeline and camera view.
  • Save often: press Ctrl + S, and save numbered versions (v01, v02…) so you can go back.
Animation editors

Where the animation lives

TimelinePlay, scrub and set start/end frames. Press I to insert a keyframe.
Dope SheetEvery keyframe as a diamond. Move, copy and re-time them here.
Graph EditorF-curves show speed. Shape ease-in, ease-out and bounces here.
PropertiesSet the frame rate and resolution, and render to a video file.
